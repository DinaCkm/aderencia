Como funciona o Nine Box?

Entenda, de forma simples, como o sistema calcula a Aderência Técnica, a Aderência Comportamental e identifica o quadrante de cada participante em cada área de interesse.

1. O que é o Nine Box?

O Nine Box é uma matriz formada por nove quadrantes. Ela permite visualizar, de maneira organizada, o nível de aderência de cada participante em relação às áreas de interesse indicadas para o Banco de Sucessores.

Tradicionalmente, uma matriz Nine Box cruza desempenho e potencial. Nesta Avaliação de Aderência, a metodologia foi adaptada para cruzar os dois resultados calculados pelo sistema:

Eixo horizontal — X

Aderência Técnica

Verifica a aproximação da formação, da experiência gerencial/interina e dos projetos estratégicos com a área analisada.

Eixo vertical — Y

Aderência Comportamental

Combina a Performance — Engajamento no Banco de Sucessores — com o alinhamento do Perfil DISC ao perfil esperado para a área.

Importante: o quadrante é definido pelo cruzamento das duas dimensões. A soma denominada “Aderência Total” ajuda a visualizar o resultado geral, mas não substitui a análise separada dos dois eixos.

2. Como o sistema chega ao quadrante?

O cálculo ocorre em quatro etapas, sempre separadamente para cada área de interesse.

1

Calcula a Aderência Técnica

Os itens validados são pontuados e convertidos para uma nota de 0 a 10.

2

Calcula a Aderência Comportamental

A Performance convertida e o Perfil DISC são combinados em uma nota de 0 a 10.

3

Classifica as notas

Cada nota é enquadrada nas faixas Baixa, Média ou Alta.

4

Realiza o cruzamento

O encontro das duas faixas determina um dos nove quadrantes.

Aderência Técnica — escala de 0 a 10

  • Pós-graduação/MBA reconhecidoaté 40 pontos
  • Experiência gerencial/interina — 5 pontos por anoaté 20 pontos
  • Projetos estratégicos da áreaaté 20 pontos
Total bruto: 0–80 pontos → convertido para a escala de 0–10

Aderência Comportamental — escala de 0 a 10

  • Performance — nota de Engajamento do ciclo, de 0 a 100convertida para 0–10
  • Perfil DISC — alinhamento dos indicadores D, I, S e C ao perfil esperado para a áreanota de 0–10
Aderência Comportamental = (Performance convertida + Perfil DISC) ÷ 2
Validação dos dados: as informações e os documentos comprobatórios são analisados pelo RH/UGP. Para a pontuação oficial, são considerados os itens aprovados. Itens pendentes podem aparecer como pontuação potencial, mas não integram a nota técnica confirmada enquanto não forem aprovados.

3. Como as notas são classificadas?

As mesmas faixas são aplicadas à Aderência Técnica e à Aderência Comportamental.

Baixade 0 a 4,9
Médiade 5,0 a 7,4
Altade 7,5 a 10

6. Dúvidas frequentes

O Nine Box aprova ou reprova o participante?

Não. O Nine Box é um instrumento de apoio à análise, ao desenvolvimento e às decisões de sucessão. O quadrante não deve ser interpretado, isoladamente, como aprovação ou reprovação.

Por que posso ter um quadrante diferente em cada área?

Porque a Aderência Técnica e o Perfil DISC são analisados em relação a cada área de interesse. As evidências e o grau de alinhamento podem variar entre as áreas.

O resultado apresentado inicialmente é definitivo?

As posições geradas a partir das informações declaradas são provisórias e estão sujeitas à validação, análise e comprovação documental pelo RH/UGP. A posição pode ser alterada após a conferência dos comprovantes.

O que acontece quando faltam dados de Performance ou DISC?

Sem os dados necessários para calcular a Aderência Comportamental, o sistema apresenta “Dados incompletos para definição do quadrante” até que as informações sejam importadas pelo RH.
